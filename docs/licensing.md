# OrgTeX Licensing Policy

## Project license

OrgTeX is distributed under the Mozilla Public License 2.0 (MPL-2.0).

The complete license text is available in the root `LICENSE` file.

OrgTeX uses MPL-2.0 because the project is intended to remain free and
open-source while supporting a modular ecosystem of extensions, integrations
and independent components.

MPL-2.0 applies copyleft at the file level.

Files belonging to OrgTeX and distributed under MPL-2.0 remain subject to the
requirements of that license when modified and redistributed.

Independent components may use other licenses when legally compatible and when
they are not modifications of MPL-covered OrgTeX files.

## Third-party software

OrgTeX may depend on or interact with third-party software such as:

- Emacs
- Org Mode
- LaTeX
- TeX-related packages
- Docker
- Python libraries
- other development and runtime tools

The use of a third-party dependency does not automatically change the license
of OrgTeX.

Each third-party dependency remains subject to its own license.

OrgTeX must not copy, redistribute or incorporate third-party source code,
assets, fonts, logos or other protected material without first verifying that
its license permits that use.

Relevant third-party licenses will be documented separately.

## Org Mode

OrgTeX may integrate with Org Mode through supported interfaces and workflows.

OrgTeX must avoid copying Org Mode source code into the project unless the
licensing implications are explicitly reviewed.

## LaTeX

OrgTeX may generate LaTeX code and may provide original `.sty` and `.cls`
files.

Original OrgTeX LaTeX files may be licensed under MPL-2.0.

LaTeX itself and individual LaTeX packages remain subject to their respective
licenses.

OrgTeX must not assume that every LaTeX package uses the same license.

## Assets

Logos, images, icons, fonts and other assets may have licensing or trademark
restrictions independent from the OrgTeX source code.

Third-party assets should not be committed to the repository unless their
redistribution rights have been verified.

## Contributions

Contributors are responsible for ensuring that contributions they submit are
legally compatible with the OrgTeX license and do not improperly include
third-party copyrighted material.
