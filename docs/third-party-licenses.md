# Third-Party Software and Licenses

OrgTeX uses or may interact with third-party software.

This document tracks relevant external dependencies and their licenses.

The list will be expanded as dependencies are introduced into the project.

## Current ecosystem dependencies

| Component | Purpose | License | Incorporated into OrgTeX |
|---|---|---|---|
| Emacs | Editor and execution environment | GPL | No |
| Org Mode | Org document authoring and export | GPL | No |
| LaTeX | Document typesetting system | LPPL ecosystem | No |

"Not incorporated" means OrgTeX currently intends to use or interact with the
software rather than copy its source code into the OrgTeX repository.

## Future dependencies

Any new runtime or development dependency should be reviewed before it becomes
a required part of OrgTeX.

The review should record:

Dependency name  
Version when relevant  
Purpose  
License  
Official source  
Whether it is distributed with OrgTeX  
Any redistribution requirements

## Assets and trademarks

Licensing of software and licensing of assets are separate concerns.

Institutional logos, fonts, icons and images must be reviewed individually
before being redistributed with OrgTeX.

For example, an OrgTeX theme may support an institution without necessarily
redistributing that institution's official logos.
