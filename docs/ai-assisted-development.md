# AI-Assisted Development Policy

## Purpose

OrgTeX permits the use of AI-assisted development tools.

AI tools may be used for activities such as:

- brainstorming
- architecture discussions
- documentation drafting
- code generation
- code review
- debugging assistance
- test generation
- refactoring suggestions

AI-generated or AI-assisted content is not accepted blindly.

Human contributors remain responsible for reviewing, understanding and testing
everything that becomes part of OrgTeX.

## Responsibility

A contribution is the responsibility of the contributor who submits it,
regardless of whether AI tools were involved in its creation.

Contributors should verify:

Correctness  
Security  
Maintainability  
Licensing compatibility  
Third-party attribution requirements  
Tests when appropriate  
Documentation when appropriate

## Third-party code

AI tools must not be used as a justification for copying code whose origin or
license is unknown.

If AI-assisted output appears to reproduce identifiable third-party code, the
contributor should investigate its origin before including it in OrgTeX.

When licensing is unclear, the safest option is to rewrite the implementation
independently or avoid including it.

## Transparency

OrgTeX does not require every AI-assisted line of code to be individually
marked.

However, substantial use of AI may be disclosed when useful for review,
especially when a contribution contains generated implementations that deserve
additional verification.

## Human review

AI-assisted code should meet the same quality standards as manually written
code.

No contribution should be merged solely because an AI system generated or
recommended it.

## Project philosophy

AI is treated as a development tool, not as a substitute for understanding the
system.

OrgTeX aims to remain understandable and maintainable by human contributors.
